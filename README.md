# DevCheck // Structural Integrity System

An automated script verification and environment auditing application engineered for software deployments. Developed as a collaborative, multi-disciplinary group project to demonstrate system validation pipelines.

## 👥 Project Contribution Breakdown
* **Shubhangini Shreya (Core Logic & Data Validation):** Engineered the behavioral verification metrics, architectural validation logic, script path rules (`main.py`), and database primary key constraint parameters.
* **Development Collaborator (Frontend UI Engine):** Constructed the responsive application interface layout, style sheets, and browser rendering operations using HTML and CSS.

## 🚀 Core Architectural Features
* **Structural Auditing:** Validation engine verifying that entry-point execution scripts safely match standard deployment targets.
* **Dependency & Security Assertions:** Pre-flight configuration check ensuring local driver packages and credential tables are properly verified before server execution.
